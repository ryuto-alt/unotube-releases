# UnoTube

公式 YouTube アプリに [Morphe Patches](https://github.com/MorpheApp/morphe-patches) と独自の変更を当てた、Android 向けのカスタム YouTube です。広告なし、ショート非表示、バックグラウンド再生、SponsorBlock など。

- ダウンロードページ: https://ryuto-alt.github.io/unotube-releases/
- 最新リリース: https://github.com/ryuto-alt/unotube-releases/releases/latest
- 改造部分のソース (GPLv3): https://github.com/ryuto-alt/unotube-src

UnoTube は Morphe Patches (https://github.com/MorpheApp/morphe-patches, GPLv3) をもとにした非公式の改造版です。Morphe 公式とは関係ありません。YouTube は Google LLC の商標で、UnoTube は Google とは関係ありません。

以前の Flutter 版 (v1.x) のリリースも Releases に残してあります。
